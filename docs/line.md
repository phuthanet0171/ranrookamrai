# LINE bot: จดยอด ถาม AI และรับสรุปตอนเช้าใน LINE

คำสั่งใหม่: `ขายมันไก่ 40, ชาเย็น 20 และไก่ทอด 12 สด 2500 โอน 1500 ค่าไก่ 800` จดหลายรายการในข้อความเดียวได้; `ลบข้าวมันไก่ 1` หรือ `ลบเมื่อวาน ข้าวมันไก่ 2 จาน` ลดจำนวนที่จดแล้วทีละเมนู

การลดจำนวนแสดงยอดเดิมและยอดใหม่บนการ์ดก่อนยืนยัน ระบบตรวจยอดเดิมอีกครั้งตอนยืนยันและเก็บรายการเดิมไว้ในประวัติ หากมีคำที่อ่านไม่ออกจะขอให้แก้ข้อความแล้วส่งใหม่โดยไม่บันทึกบางส่วน

เงินสดหมายถึงเงินจากยอดขาย ไม่รวมเงินทอนตั้งต้น ถ้าหยิบไปซื้อของให้กรอกยอดก่อนหยิบและบันทึกค่าใช้จ่ายแยก ต้องรัน `python pipeline\migrate.py 010_line_corrections` หลังอัปเดตโค้ดก่อนใช้คำสั่งลดจำนวน

## ทำอะไรได้

| พิมพ์ใน LINE | ระบบทำอะไร |
|---|---|
| `มันไก่ 40 ชาเย็น 20 สด 1500 โอน 800 ค่าไก่ 600` | อ่านเป็นยอดขาย เงินที่รับ และรายจ่าย → ส่งการ์ดให้ตรวจ → กด **✓ ยืนยัน** จึงบันทึก |
| `เมื่อวาน มันไก่ 35` | บันทึกเป็นของเมื่อวาน |
| `ลบข้าวมันไก่ 1` | แสดงจำนวนเดิม → ใหม่ แล้วให้กดยืนยันก่อนแก้ยอด |
| `เมื่อวานกำไรเท่าไหร่` · `เดือนนี้เมนูไหนขายดี` | ผู้ช่วย AI ตอบ (ตัวเลขทุกตัวเติมจากฐานข้อมูล) |
| `สรุปวันนี้` · `วิธีใช้` | ตอบทันที ไม่ใช้ AI |
| (ทุกเช้า 08:00) | สรุปเมื่อวาน + วันนี้ควรเตรียมอะไร **เขียนโดย AI** ส่งเข้า LINE เอง |

### การอ่านข้อความ (AI ช่วย แต่แต่งเองไม่ได้)
1. **กฎก่อน** (`web/lib/lineparse.ts`): จับชื่อเมนูและชื่อเรียกอื่น, `สด`/`โอน`, `ค่า…`/`จ่าย…`/`ซื้อ…` = รายจ่าย, เลขไทย, `1,500`
2. ถ้ามีคำที่กฎไม่รู้จัก **Gemini ช่วยอ่าน** โดยต้องตอบเป็น JSON ตาม schema และเลือกได้เฉพาะเมนูที่มีในร้าน
3. `checkAiParse()` ทิ้งทุกอย่างที่ไม่มีในข้อความ: **ตัวเลขต้องเป็นเลขที่เจ้าของร้านพิมพ์เอง** เมนูต้องมีจริง
4. ไม่มีอะไรถูกบันทึกจนกว่าเจ้าของร้านจะกดยืนยัน และ `line_draft_confirm()` บันทึกได้ครั้งเดียว (กดซ้ำไม่ซ้ำ)

### สรุปตอนเช้าโดย AI (`web/lib/morning.ts`)
AI เขียนข้อความด้วย placeholder เช่น `{y_day.revenue}` ระบบตรวจว่าไม่มีตัวเลขหรือคำบอกทิศทางที่ AI พิมพ์เอง แล้วจึงเติมค่าจริง
ไม่ผ่านให้เขียนใหม่ 1 ครั้ง ถ้ายังไม่ผ่านหรือ Gemini ล่ม จะส่งข้อความจากระบบแทน เจ้าของร้านจึงได้ข้อความที่ถูกต้องทุกเช้า
ทุกครั้งบันทึกใน **ประวัติการทำงาน** ว่าใช้ AI หรือข้อความจากระบบ พร้อมจำนวน token

## ตั้งค่า (ฟรี ใช้เวลาประมาณ 15 นาที)

### 1. ฐานข้อมูล
```
python pipeline\migrate.py 009_line
```

### 2. สร้าง LINE Official Account + Messaging API
1. ไปที่ https://developers.line.biz/console/ แล้วเข้าสู่ระบบด้วย LINE
2. **Create a new provider** (ชื่ออะไรก็ได้ เช่น ร้านรู้กำไร)
3. **Create a Messaging API channel** → ระบบจะให้สร้าง LINE Official Account (เลือกแพ็กเกจฟรี)
4. ในแท็บ **Basic settings** คัดลอก **Channel secret**
5. ในแท็บ **Messaging API**
   - **Channel access token (long-lived)** → กด Issue แล้วคัดลอก
   - จด **Bot basic ID** (ขึ้นต้นด้วย `@`)

### 3. ใส่ค่าใน Vercel (Settings → Environment Variables) แล้ว Redeploy
| ชื่อ | ค่า |
|---|---|
| `LINE_CHANNEL_SECRET` | Channel secret |
| `LINE_CHANNEL_ACCESS_TOKEN` | Channel access token |
| `LINE_BOT_ID` | Bot basic ID เช่น `@123abcde` |

> ใส่เองในหน้า Vercel เท่านั้น อย่าวางค่าพวกนี้ในแชตหรือใน git

### 4. ตั้ง Webhook
ใน LINE Developers → แท็บ **Messaging API**
- **Webhook URL**: `https://<โดเมนของคุณ>.vercel.app/api/line/webhook` → กด **Verify** (ต้องขึ้น Success)
- เปิด **Use webhook**
- ใน **LINE Official Account features** → Auto-reply messages → **Disabled**, Greeting messages → Disabled (ให้บอทตอบเอง)

### 5. เชื่อม LINE กับร้าน
เว็บ → **ตั้งค่า → เชื่อม LINE** → กด **สร้างรหัสเชื่อม LINE** → เพิ่มเพื่อนบอท → ส่งรหัส 6 หลักในแชต
เชื่อมได้หลายคนต่อร้าน (เช่น เจ้าของ + พนักงาน) และเลิกเชื่อมได้จากหน้าเดียวกัน

### 6. ให้สรุปตอนเช้าเข้า LINE
เว็บ → **ตั้งค่า → การแจ้งเตือนอัตโนมัติ** → เพิ่ม **สรุปตอนเช้า** → ส่งไปที่ **LINE** → บันทึก
กด **ลองส่งตอนนี้** เพื่อทดสอบ

## โควตาและค่าใช้จ่าย
- **ตอบกลับ (reply) ฟรีไม่จำกัด**: การจดยอดและถาม AI ใช้ reply ทั้งหมด
- **ส่งเอง (push)** เช่นสรุปตอนเช้า: แพ็กเกจฟรีของ LINE OA ส่งได้ประมาณ 300 ข้อความ/เดือน
  (1 ร้าน × 1 คน × สรุปเช้า 26 วัน ≈ 26 ข้อความ ใช้ได้สบาย)

## แก้ปัญหา
| อาการ | สาเหตุ |
|---|---|
| Verify ขึ้น 500 | ยังไม่ได้ใส่ `LINE_CHANNEL_SECRET` / `LINE_CHANNEL_ACCESS_TOKEN` หรือยังไม่ Redeploy |
| Verify ขึ้น 401 | Channel secret ใน Vercel ไม่ตรงกับใน LINE Developers |
| บอทไม่ตอบ | ยังไม่เปิด Use webhook หรือ Auto-reply ยังเปิดอยู่ · ดู **ตั้งค่า → ขั้นสูง → ประวัติการทำงาน** |
| "รหัสไม่ถูกต้องหรือหมดอายุ" | รหัสใช้ได้ 15 นาทีและใช้ได้ครั้งเดียว สร้างใหม่ได้ |
| "ไม่รู้จัก: …" | เพิ่มชื่อที่พิมพ์บ่อยเป็น **ชื่อเรียกอื่น** ของเมนูในหน้าตั้งค่า |
