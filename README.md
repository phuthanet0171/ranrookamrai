# ร้านรู้กำไร (Raan Roo Kam Rai)

เว็บแอปพลิเคชันผู้ช่วยวิเคราะห์ยอดขายสำหรับร้านค้าขนาดเล็กที่ไม่มีระบบ POS เช่น ร้านอาหารตามสั่ง ร้านก๋วยเตี๋ยว แผงลอย และคาเฟ่ขนาดเล็ก ช่วยให้เจ้าของร้านบันทึกยอดขาย รายจ่าย เงินสด และเงินโอนในแต่ละวันได้อย่างสะดวก พร้อมสรุปผลการดำเนินงานให้อยู่ในรูปแบบที่เข้าใจง่าย

ระบบสามารถคำนวณยอดขาย ต้นทุน กำไรโดยประมาณ และตรวจสอบเงินขาดหรือเกินจากข้อมูลที่เจ้าของร้านบันทึก นอกจากนี้ยังวิเคราะห์ข้อมูลย้อนหลังเพื่อแนะนำจำนวนสินค้าที่ควรเตรียมในวันถัดไป โดยใช้สูตรที่กำหนดไว้อย่างชัดเจน ไม่ให้ AI สร้างตัวเลขขึ้นเอง

## ฟีเจอร์หลัก

- บันทึกจำนวนสินค้าที่ขายในแต่ละวัน
- บันทึกรายรับจากเงินสดและเงินโอน
- บันทึกและจัดหมวดหมู่รายจ่ายของร้าน
- คำนวณยอดขาย ต้นทุน และกำไรโดยประมาณ
- ตรวจสอบเงินสดและเงินโอนว่าขาดหรือเกินจากยอดขาย
- แสดง Dashboard สรุปผลย้อนหลัง 7 วัน
- วิเคราะห์เมนูขายดีและแนวโน้มยอดขาย
- แนะนำจำนวนสินค้าที่ควรเตรียมจากข้อมูลย้อนหลัง
- ถามข้อมูลร้านด้วยภาษาธรรมชาติผ่าน AI
- บันทึกยอดและสอบถามข้อมูลผ่าน LINE
- แสดงข้อมูลให้ตรวจสอบและกดยืนยันก่อนบันทึกหรือแก้ไขรายการจาก LINE
- ส่งสรุปยอดขายและการแจ้งเตือนตามเวลาที่กำหนด

## การทำงานของ AI

ระบบใช้ Gemini ร่วมกับ Function Calling เพื่อเลือกเครื่องมือสำหรับดึงข้อมูลจากฐานข้อมูล โดยการคำนวณยอดขาย ต้นทุน กำไร และการพยากรณ์จะดำเนินการด้วย SQL และ Business Logic ของระบบ จากนั้น AI จะทำหน้าที่อธิบายข้อมูลให้อ่านง่าย

```text
ผู้ใช้ถามคำถาม
      ↓
AI เลือกเครื่องมือที่เหมาะสม
      ↓
ระบบดึงและคำนวณข้อมูลจากฐานข้อมูล
      ↓
ตรวจสอบผลลัพธ์
      ↓
AI อธิบายข้อมูลให้ผู้ใช้
```

แนวทางนี้ช่วยลดความเสี่ยงที่ AI จะสร้างตัวเลขทางการเงินขึ้นเอง และทำให้คำตอบสามารถตรวจสอบย้อนกลับได้

## การทำงานผ่าน LINE

เจ้าของร้านสามารถบันทึกหลายรายการภายในข้อความเดียว เช่น

```text
ข้าวมันไก่ 40 ชาเย็น 20 สด 1500 โอน 800 ค่าไก่ 600
```

ระบบจะแปลงข้อความเป็นข้อมูลแบบมีโครงสร้างและแสดงรายการให้ตรวจสอบก่อน ผู้ใช้ต้องกดยืนยันจึงจะบันทึกลงฐานข้อมูล นอกจากนี้ยังรองรับการแก้ไขจำนวน เช่น

```text
ลบข้าวมันไก่ 1
```

ระบบจะแสดงจำนวนเดิมและจำนวนใหม่ก่อนให้ผู้ใช้ยืนยันการแก้ไข

## ระบบอัตโนมัติ

ระบบสามารถทำงานตามเวลาที่กำหนดและส่งข้อความผ่านหน้าเว็บหรือ LINE ได้แก่

- แจ้งเตือนเมื่อร้านยังไม่ได้บันทึกยอดขาย
- ส่งสรุปยอดขายและกำไรโดยประมาณในตอนเช้า
- แจ้งเตือนเมื่อพบเงินขาดเกินค่าที่กำหนด
- ส่งรายงานสรุปผลการดำเนินงานประจำสัปดาห์

## เทคโนโลยีที่ใช้

- **Frontend และ Backend:** Next.js, TypeScript
- **Database:** Supabase PostgreSQL
- **Artificial Intelligence:** Gemini API และ Function Calling
- **Messaging:** LINE Messaging API
- **Automation:** GitHub Actions และ Vercel Cron
- **Deployment:** Vercel

> กำไรที่แสดงในระบบเป็น “กำไรโดยประมาณ” ซึ่งคำนวณจากราคาขาย ต้นทุนสินค้า และรายจ่ายที่บันทึกไว้ อาจยังไม่รวมค่าใช้จ่ายทั้งหมด เช่น ค่าแรง ค่าเช่า ค่าไฟ และของเสีย
